## Ответы на контрольные вопросы

1. Какой объект однозначно определяет версию данных в DVC?

Состояние данных определяется хэшем содержимого, записанным в
data.dvc. Для директории это хэш объекта-манифеста с суффиксом .dir,
который ссылается на содержимое файлов. Конкретный Git-коммит или
тег позволяет выбрать нужную редакцию data.dvc.

2. Почему одного Git-коммита недостаточно без DVC remote?

Git-коммит хранит метаданные, но не сами CSV. Без remote или другой
доступной копии объектов DVC после потери workspace и cache
восстановить данные по одному коммиту нельзя. В работе чистый
клон восстановил CSV командой dvc pull из локального remote.

3. Чем Dataset version отличается от Dataset ID в ClearML?

Version — заданная пользователем метка, например 1.1.0.
Dataset ID — уникальный идентификатор конкретного Dataset.
В работе скачивание выполнялось по ID, поэтому не зависело
от поиска по имени или от последней созданной версии.

4. Почему finalize() нельзя считать созданием следующей версии?

finalize() завершает текущий Dataset и делает его неизменяемым.
Следующая версия создаётся отдельным вызовом Dataset.create(),
получает новый ID и при необходимости ссылку на родителя.

5. Как доказать, что 2.0.0 создана от базы, а не от 1.1.0?

get_dependency_graph() показал у Dataset
ecdd27025172462586774221b78baba1 единственного родителя
8665e74fb58643179ccf9d9b4f120d39.
WINE_ID отсутствует среди предков. Скачанная версия содержит
только изменённый Iris, без Wine.

6. Что произойдёт, если после git switch не выполнить DVC checkout?

Git переключит метаданные, но CSV в рабочей папке могут остаться
от предыдущей версии. Для приведения данных к выбранной версии
нужен dvc checkout; если объектов нет в cache, потребуется dvc pull.

7. В каком сценарии удобнее DVC, а в каком ClearML Dataset?

DVC удобен для совместного изменения кода и данных в Git-ветках:
в работе удалось объединить добавление Wine и признаки Iris.
ClearML Dataset удобен для хранения отдельных завершённых версий
с явными родителями и получения данных по ID через SDK.
В работе три версии независимо скачаны и проверены.
